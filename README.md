Описание проекта

Программа визуализирует динамическую систему случайно генерируемых фейерверков с использованием библиотеки Pygame. Каждый фейерверк и его составные частицы имеют строго ограниченное время жизни, рассчитываемое в кадрах. В проекте реализовано физическое поведение элементов с учетом векторов скоростей и сил гравитации. 

Функциональные возможности

Основной функционал

* Автоматическая случайная генерация фейерверков на экране
* Ограничение времени существования (времени жизни) как самого фейерверка, так и отдельных его частиц
* Проектирование архитектуры приложения с применением объектно-ориентированного подхода (ООП)

Дополнительный функционал

* Генерация разноцветных вспышек с эффектом плавного затухания и регулировкой альфа-канала прозрачности
* Реалистичное поведение частиц под воздействием регулируемой силы гравитации

Требования к системе

* Python: 3.9 или выше
* Операционная система: Windows / macOS / Linux
* Библиотеки: pygame==2.6.1

Установка и запуск
1. Клонирование репозитория

bash

git clone https://github.com/username/animation_project.git
cd animation_project

2. Создание и активация виртуального окружения

Windows:

bash

python -m venv venv
venv\Scripts\activate

macOS/Linux:

bash

python3 -m venv venv
source venv/bin/activate


3. Установка зависимостей

bash
pip install -r requirements.txt


4. Запуск программы

bash
python main.py

Назначение основных модулей:

* main.py — точка входа в программу, запускающая приложение.
* app.py — класс App, управляющий главным циклом программы, обработкой событий и обновлением кадров.
* animation_model.py — классы Firework и Particle, содержащие внутреннюю логику, математические расчеты траекторий и гравитации.
* renderer.py — класс Renderer, отвечающий исключительно за графическую отрисовку объектов и работу с прозрачностью на холсте Pygame.

Пример использования

Запуск программы

bash
python main.py


После запуска откроется графическое окно размером 800x600 пикселей, в котором на фоне ночного неба начнется цикличная симуляция разноцветных праздничных салютов. Каждая вспышка плавно рассеивается под действием силы тяжести и исчезает. Закрытие программы осуществляется нажатием на стандартный графический крестик окна.
